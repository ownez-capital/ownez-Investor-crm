Problems in this flow

  • The "Enter-through" path: Chad can log a new activity and hit Enter without changing the Next Action. If the old Next Action Date was in the past, the prospect stays overdue on the dashboard — even though he just touched them.
  • No audit of fulfillment: There's no way to tell from the record whether Chad actually did the thing he committed to, or whether the newly logged activity is something unrelated.
  • No in-flow "kill lead" path: Marking a lead Dead requires abandoning Quick Log entirely, navigating to Person Detail, using the stage bar, picking a Lost Reason, then dismissing a second post-stage-change prompt.

How it fixes each problem

  • Explicit close-out: If there's an overdue commitment, Chad must choose Fulfilled, Still pending, or Replace. No more silent Enter-through leaving overdue flags behind.
  • Audit trail in timeline: Every commitment is logged as its own event; activities that fulfill commitments are explicitly linked. Eric can look at any prospect and see which commitments Chad kept.
  • Dashboard tells the truth: "Still pending" keeps the prospect overdue — because the commitment genuinely wasn't done.
  • In-flow drop: "Drop lead" link inside the Next Action prompt opens an inline Dead/Nurture panel. No navigation. Any open commitment auto-cancels.

Three concrete scenarios — what Chad experiences today vs proposed

Scenario A — The "happy path" (commitment actually fulfilled)

Setup
Chad set "Follow up · Q3 deck · due Mar 5". On Mar 5 he actually sends the deck.
Today
Logs email → Next Action prompt → types new follow-up → Enter. Old commitment silently overwritten. Timeline just shows "Mar 5 Email sent". Was it the follow-up? No way to tell.
Logs email → Close-out prompt appears → hits F → Next Action prompt → sets new follow-up → Enter. Timeline: "Mar 5 Email · ✓ Fulfilled: Q3 deck follow-up" · "Mar 5 ◉ Commitment set: Schedule meeting".

Scenario B — Unrelated activity while commitment is still open

Setup
Chad set "Call Robert · due Mar 5". On Mar 7 he logs: "CPA told me Robert is traveling this week". He has NOT called Robert yet.
Today
Logs note → Next Action prompt → Enter (keeps old values). Old commitment stays. BUT: Days Idle resets. Dashboard shows "Overdue 2d" (based on date) but also shows "touched today". Mixed signals; Chad can't see that he still owes the call.
Logs note → Close-out prompt → hits P (Still pending) → done, no new prompt. Commitment stays open. Dashboard shows honest "Overdue 2d". Timeline: "Mar 7 Note · (did not fulfill) · Still open: Call Robert (2d)".

Scenario C — Prospect said no

Setup
Chad calls Robert. Robert says he's not interested. Chad wants to kill the lead and move on.
Today
Logs call → Next Action prompt (must set something) → types placeholder → Enter → navigate to Person Detail → stage bar → Dead → confirm → pick Lost Reason → handle SECOND prompt → Enter. ~8 clicks, two prompts, lots of friction.
Logs call → Next Action prompt → clicks Drop lead ▸ → Dead pill → pick Lost Reason → Enter. 3 clicks. Any open commitment auto-cancels. History fully preserved for resurrection.
